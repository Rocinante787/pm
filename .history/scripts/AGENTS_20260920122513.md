# Scripts Directory

This folder contains startup and shutdown scripts for macOS, Linux, and Windows, managing the execution of the Project Management MVP app in Docker or locally via `uv`.

## Scripts

- `start.sh` (Mac / Linux): Builds the Docker image `pm-app` and runs it in the background on port 8000 with `./data` mounted for persistent storage and `.env` loaded. Falls back to local `uv run uvicorn` if Docker is unavailable.
- `stop.sh` (Mac / Linux): Stops and removes the running `pm-app` Docker container or terminates the local process.
- `start.ps1` & `start.bat` (Windows): Builds and starts the `pm-app` Docker container with volume mount and `.env`, or runs locally via `uv` if Docker is not installed.
- `stop.ps1` & `stop.bat` (Windows): Stops and removes the `pm-app` container or local server process.

## Manual Docker Commands

### Build Image
```bash
docker build -t pm-app .
```

### Run Container
```bash
docker run -d \
  --name pm-app \
  -p 8000:8000 \
  -v "$(pwd)/data:/app/data" \
  --env-file .env \
  pm-app
```

### Stop Container
```bash
docker stop pm-app && docker rm pm-app
```

### View Logs
```bash
docker logs -f pm-app
```

## Local Development (Without Docker)

From the project root:
```powershell
cd backend
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
Access the application at `http://localhost:8000`.
