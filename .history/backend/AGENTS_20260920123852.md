# Backend Architecture & Specifications

## Overview

The backend is built with Python 3.12+ and FastAPI, managed using `uv` as the package manager. It serves the REST API endpoints and hosts the static Next.js frontend export from `/`.

## Technology Stack

- Language: Python 3.12+
- Web Framework: FastAPI
- Server: Uvicorn
- Package Manager: `uv`
- Data Validation: Pydantic v2
- Testing: pytest, pytest-asyncio, HTTPX

## Directory Structure

```
backend/
├── app/
│   ├── __init__.py
│   └── main.py          # FastAPI application, route definitions, static mount
├── static/
│   └── index.html       # Placeholder HTML for Part 2 (replaced by Next.js export in Part 3)
├── tests/
│   ├── __init__.py
│   └── test_main.py     # Backend route tests (health check, static serving)
├── pyproject.toml       # Python package configuration and dependencies
└── README.md            # Service overview
```

## Current Endpoints (Part 2)

- `GET /api/health`: Returns `{"status": "ok"}` for container and service health checks.
- `GET /`: Serves static HTML files from `backend/static/` with SPA routing support.

## Testing

Run tests with `uv`:
```powershell
cd backend
uv run pytest
```
